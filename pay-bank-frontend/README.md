# Pay Bank Frontend

Frontend web de Pay Bank (Angular 22, standalone, zoneless, signals-first).

La arquitectura, convenciones y puesta en marcha están descritas en [docs/constitution.md](docs/constitution.md).

```bash
npm install     # instalar dependencias
npm start       # servidor de desarrollo en http://localhost:4200
npm test        # tests unitarios (Vitest)
npm run build   # build de producción
```
